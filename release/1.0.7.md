# Kairos 1.0.7

Chrome extension with the latest player controls and platform support.

- Semantic island icons and fast localized tooltips, including sidebar actions.
- Visit-only and global disabling, with an enable button in the extension popup.
- Quieter glass styling and improved access to native player menus.
- Experimental Coursera, Udemy and TED playback support alongside YouTube and Bilibili.
- Updated bilingual documentation and colourful website platform icons.

Coursera, Udemy and TED have passed simulated-page routing and player tests. Authenticated course playback still needs live verification. Cross-origin embedded players and DRM-protected screenshots are currently unsupported. This version adds host access for www.coursera.org, www.udemy.com and www.ted.com.

## Install / 安装

For one-click installation, use the [Chrome Web Store](https://chromewebstore.google.com/detail/kairos-your-ai-video-note/idhcehbbnfdklhbondmbpplpcdbnodfp). The Store version follows its own review schedule.

To install this release manually:
1. Download and extract `kairos-1.0.7-chrome.zip` into a folder you will keep.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Choose **Load unpacked** and select the extracted folder containing `manifest.json`.
4. Refresh your video tabs.

手动安装此版本：下载并解压 ZIP，打开 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹，然后刷新视频页。保留该文件夹以便扩展正常运行。

The ZIP contains a production build and can also be uploaded to Chrome Web Store. Verify it with the attached SHA-256 file.
