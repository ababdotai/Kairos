# Kairos 1.0.8 — Better course notes and replay

- Keep course, lesson and timestamp together. Reopen the saved lesson and seek to the recorded moment once its player is ready; isolate Bilibili multi-part notes.
- Improved Coursera integration: an on-demand, content-sized notes drawer that does not resize the course player. Open it from the island footer; close with Esc or the close button.
- Separate notes-panel, Dashboard and Settings controls, plus correctly anchored tooltips.
- Explicit Enter/check confirmation saves screenshot-only notes. Save failures keep the draft and offer inline retry feedback.
- Recover gracefully after an extension reload and retain unsaved text for copying.
- Quieter console output, with genuine persistence failures still reported.

## Install

[Chrome Web Store](https://chromewebstore.google.com/detail/kairos-your-ai-video-note/idhcehbbnfdklhbondmbpplpcdbnodfp) updates follow Google's review schedule.

For manual installation, extract `kairos-1.0.8-chrome.zip`, enable Developer mode at `chrome://extensions`, choose **Load unpacked**, then select the extracted folder. Refresh existing video tabs.

The same ZIP is suitable for Chrome Web Store upload. The SHA-256 file is attached.

## Verification and limits

Regression tests cover course identity, replay requests, actual HTML video seeking, save/retry recovery, drawer sizing and layout isolation, runtime teardown, and the production content bundle. Build and ZIP integrity verified.

Coursera layout anchors were inspected on an authenticated lesson page. A complete authenticated Coursera replay has not been verified end to end. Coursera, Udemy and TED support remains experimental; cross-origin embedded players and DRM-protected capture are not supported.
