## 💭 专注留给视频，想法始终属于你

看视频时，一个好想法不该被切换软件、截图粘贴和整理文字打断。Kairos 把记录留在灵感发生的地方，让 AI 安静地帮忙，而你始终主导思考。

- 🫧 **保持心流**：随手记录，无需离开视频。
- 🧠 **增强思考**：AI 结合画面与上下文整理笔记，保留你的原始表达。
- ⏱️ **连接知识**：用时间轴串起重要时刻，让回顾不再靠拖动进度条碰运气。
- 🔐 **本地优先**：笔记保存在自己的设备上，AI 按需启用。

**让观看更高效，也让理解更深入、学习更主动。**

## ✨ 从一闪而过，到随时拾起

- **✍️ 想到就记。** 打几个关键词，或拖动截取一块画面。保存后自动继续播放，跟上思路。
- **🪄 AI 搭把手。** 按需开启自动润色，结合画面与可用字幕，把零散关键词整理成清晰的笔记。Dashboard 同时保留你的原文和 AI 版本。
- **⏱️ 回到那一刻。** 时间轴上的光点标出每条笔记，点击即可跳转。重播时笔记自动浮现，悬浮即可继续阅读。
- **🫧 不抢画面。** 可移动的玻璃灵动岛，在你移开鼠标后淡入背景；需要时再展开。
- **📚 让记录派上用场。** 用纵向或横向折返时间轴浏览笔记，生成 AI 总结、导出 Markdown，或把选中的笔记变成可下载的 HTML 网页。

## 🎬 陪你在哪儿看

**YouTube · 哔哩哔哩** — 已支持。

**Coursera · Udemy · TED** — 实验性支持，登录后的课程播放仍待实站验证。

仅在支持的视频播放页面启用，不打扰首页预览。目前不支持跨域嵌入播放器，也不支持受 DRM 保护的画面截图。

## 🚀 三步，记下第一条

1. **安装插件：** 前往 [Chrome 网上应用店](https://chromewebstore.google.com/detail/kairos-your-ai-video-note/idhcehbbnfdklhbondmbpplpcdbnodfp)免费安装。
2. **打开视频，启用 Kairos：** 直接打字，或在画面上拖动框选截图。
3. **回车保存：** 如需 AI 帮忙，在设置中连接自己的 AI 服务，再开启自动润色。

手动记笔记无需 API 密钥。插件免费，选用 AI 时的 API 费用由对应服务商收取。

## 🔐 你的笔记，你来决定

笔记和截图默认保存在设备本地。使用 AI 功能时，相关笔记、画面和／或字幕上下文会发送给你选择的服务商。API 密钥与偏好设置使用 Chrome 同步存储。

分享网页可在本地预览并下载 HTML。公开链接需先[配置托管服务](doc/share-pages-setup.md)，再主动发布；默认不会开启公开托管。
